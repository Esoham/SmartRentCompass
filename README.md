# SmartRentCompass

C#/.NET educational apartment search prototype using locally seeded example data.

## Where to start

- [Console application](SmartRentCompass/Program.cs)
- [Search and comparison logic](SmartRentCompass/SmartRentCompass.cs)
- [Example data](SmartRentCompass/TestData.cs)
- [Separate web project](SmartCompassweb/)

The code demonstrates simple search filters, price comparison, notifications, and other sample decision helpers. Example records and some helper outputs are simulated; there is no claim of live rental listings or independently verified calculations.

## Local exploration

The console project targets .NET 7. From the repository root, use `dotnet run --project SmartRentCompass/SmartRentCompass.csproj` with a suitable SDK. Execution has not been independently verified in this portfolio review.

## Future improvements

Add automated tests, captured screenshots, a supported framework target, validated data sources, and explicit limitations for sample calculations.
